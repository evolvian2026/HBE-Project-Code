# 0011. Activity counts toward grades as a capped process score

Status: Accepted (2026-10-08)

## Context

Activity is graded, so it must be hard to game and explainable.

## Decision

A process score built from capped, filtered metrics with a per-criterion breakdown visible to students.

## Consequences

Commit attribution must be reliable (immutable GitHub ids, claimable unattributed commits).
